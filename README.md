# Veille Monétique UEMOA

Veille quotidienne des innovations de paiement et de la monétique : Bénin, UEMOA, Afrique et monde.

- `index.html` : la page du site.
- `data.json` : les actualités, le radar des technologies, les échéances et le point de la semaine. Ce fichier est mis à jour automatiquement matin et soir.
- `btp-conciergerie.json` : les rubriques BTP & presse (actualités du BTP, revue de presse) et Conciergerie (guide de lancement, liste de départ, actualités du secteur, échéances). Mis à jour automatiquement chaque matin, indépendamment de `data.json`.

Site publié avec GitHub Pages.
